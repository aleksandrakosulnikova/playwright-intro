**Playwright** 

### Как настроить проект через клонирование?

1. Клонировать репозиторий
2. Отвязать проект от Git преподавателя
3. Добавить проект в свой Git
4. Установить зависимости: npm install
5. Установить браузеры Playwright: npx playwright install
6. Добавить необходимые переменные окружения
7. Создать новую ветку и начать писать тесты


### Запуск тестов
1. Необходимые команды для запуска тестов в терминале:
- Запуск всех тестов: npx playwright test
- Запуск с отображением браузера: npx playwright test --chromium (название)
- Запуск конкретного теста: npx playwright test -g "название теста"
- Запуск тестов в режиме UI: npx playwright test --ui

2. После выполнения тестов: npx playwright show-report
